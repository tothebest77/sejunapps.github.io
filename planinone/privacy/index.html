PlanInOne 개인정보처리방침

시행일: 2026년 9월 21일

PlanInOne(이하 “앱”)은 사용자의 개인정보와 사용자 데이터를 중요하게 생각하며, 사용자가 안심하고 앱을 이용할 수 있도록 개인정보 보호를 위해 노력합니다. 본 개인정보처리방침은 앱이 어떤 정보를 처리하고 해당 정보가 어떻게 이용, 저장 및 관리되는지 설명합니다.

현재 버전의 주요 원칙
PlanInOne은 현재 사용자 계정이나 로그인을 요구하지 않으며, 사용자가 입력한 Task, Event 및 Project 데이터는 기본적으로 사용자의 기기에 저장됩니다. 현재 이러한 일정 데이터를 PlanInOne 개발자가 운영하는 서버에 저장하지 않습니다.

1. 앱에서 처리하는 정보

PlanInOne은 일정, 할 일(Task), 이벤트(Event), 프로젝트(Project)를 관리할 수 있는 일정 관리 애플리케이션입니다. 사용자가 앱에 직접 입력하는 정보에는 Task 및 Event의 제목, 날짜와 시간, 설명, 사용자가 직접 입력한 장소 또는 위치, 우선순위, 진행 상태, 프로젝트 정보, 알림 설정, 색상 및 기타 일정 관리 설정 등이 포함될 수 있습니다. 이러한 정보는 사용자가 요청한 일정 관리 기능을 제공하기 위해 처리됩니다.

2. 데이터 저장

Task, Event, Project 등 사용자가 앱에 입력한 일정 관리 데이터는 기본적으로 사용자의 기기에 저장됩니다. 현재 PlanInOne은 이러한 일정 데이터를 PlanInOne 개발자가 운영하는 서버에 저장하지 않습니다.

앱에서 제공하는 백업 또는 복원 기능을 사용하는 경우 사용자는 자신의 데이터를 파일 형태로 관리할 수 있습니다. 또한 Android 운영체제의 백업 기능이 활성화된 경우 일부 앱 데이터가 사용자의 기기 또는 Google 계정 설정에 따라 운영체제의 백업 기능을 통해 처리될 수 있으며, 이 경우 해당 운영체제 및 관련 서비스의 정책과 설정이 적용됩니다.

3. 위치 정보

PlanInOne에서는 Task 또는 Event에 장소나 위치를 사용자가 직접 입력할 수 있습니다. 사용자가 직접 입력한 위치 정보는 일정 관리 기능을 위해 사용되며 기본적으로 사용자의 기기에 저장됩니다.

현재 PlanInOne은 기기의 GPS를 이용하여 사용자의 정확한 위치 또는 대략적인 위치를 수집하지 않습니다.

4. 날씨 정보

PlanInOne은 일정 관리 편의를 위해 날씨 정보를 제공할 수 있습니다. 날씨 기능은 사용자가 앱에서 선택한 지역을 기준으로 외부 기상 정보 서비스를 통해 날씨 정보를 조회할 수 있습니다. 현재 날씨 정보를 제공하기 위해 기기의 GPS 위치를 수집하거나 사용하지 않습니다.

5. 알림 및 리마인더

PlanInOne은 사용자가 설정한 Task 또는 Event의 알림을 제공하기 위해 Android의 알림 및 알람 관련 기능을 사용할 수 있습니다. 또한 기기 재시작 후 필요한 알림을 다시 설정하기 위해 Android 운영체제가 제공하는 관련 기능을 사용할 수 있습니다. 이러한 기능은 사용자가 설정한 일정과 리마인더를 적절한 시간에 알려주기 위한 목적으로 사용됩니다.

6. 인터넷 사용

PlanInOne은 날씨 정보와 같이 인터넷 연결이 필요한 기능을 제공하기 위해 네트워크에 접속할 수 있습니다. 현재 사용자가 입력한 Task, Event 및 Project 데이터를 PlanInOne 개발자가 운영하는 서버로 전송하기 위한 목적으로 인터넷을 사용하지 않습니다.

7. 제3자 제공 및 데이터 공유

현재 PlanInOne은 사용자가 입력한 Task, Event 및 Project 데이터를 PlanInOne 개발자가 운영하는 서버를 통해 다른 사용자에게 제공하거나 판매하지 않습니다. 현재 버전에는 사용자 행동을 추적하기 위한 광고 SDK 또는 분석 SDK가 포함되어 있지 않습니다.

향후 사용자 간 Task 또는 Project 공유, 클라우드 동기화 등 온라인 기능이 추가되는 경우, 해당 기능에서 처리되는 데이터의 종류, 처리 목적, 공유 대상 및 보관 방법 등을 실제 기능 제공에 앞서 본 개인정보처리방침에 반영하고 필요한 경우 사용자에게 안내합니다.

8. 데이터 보관 및 삭제

PlanInOne의 일정 관리 데이터는 기본적으로 사용자의 기기에 저장됩니다. 사용자는 앱에서 제공하는 삭제 기능을 이용하여 Task, Event 및 Project 등의 데이터를 삭제할 수 있습니다.

앱을 삭제하거나 앱 데이터를 삭제하면 기기에 저장된 데이터도 삭제될 수 있습니다. 다만 Android 운영체제 또는 사용자가 이용하는 백업 서비스에 의해 별도의 백업 데이터가 존재하는 경우 해당 서비스의 정책과 설정이 적용될 수 있습니다. 현재 PlanInOne은 자체 사용자 계정을 운영하지 않으므로 별도의 서버 계정 삭제 절차는 제공하지 않습니다.

9. 데이터 보안

PlanInOne은 앱에서 처리되는 사용자 데이터를 보호하기 위해 불필요한 개인정보 또는 민감한 정보에 대한 접근을 최소화하는 것을 원칙으로 합니다. 인터넷 통신이 필요한 기능에서는 가능한 범위에서 안전한 통신 방식을 사용하며, 앱 기능 제공에 필요하지 않은 사용자 데이터를 개발자가 운영하는 서버로 전송하지 않습니다.

10. 아동의 개인정보

PlanInOne은 일정 및 할 일 관리를 위한 일반적인 생산성 애플리케이션이며, 아동의 개인정보를 의도적으로 수집하기 위한 서비스를 제공하지 않습니다. 앱의 대상 연령 및 Google Play의 관련 정책에 따라 필요한 보호 조치를 적용합니다.

11. 향후 기능 변경

PlanInOne에는 향후 Task 공유, Project 공유 및 공동 작업, 클라우드 동기화, 여러 기기 간 데이터 동기화 또는 계정 기반 서비스 등의 기능이 추가될 수 있습니다. 이러한 기능의 추가로 개인정보 또는 사용자 데이터의 수집, 저장, 이용 또는 공유 방식이 변경되는 경우 실제 기능 제공에 앞서 본 개인정보처리방침을 적절하게 변경하고, 필요한 경우 사용자에게 관련 내용을 안내합니다.

12. 개인정보처리방침 변경

앱 기능 또는 관련 법령 및 정책의 변경에 따라 본 개인정보처리방침이 변경될 수 있습니다. 중요한 변경사항이 있는 경우 앱, 웹사이트 또는 기타 적절한 방법을 통해 안내할 수 있습니다. 최신 개인정보처리방침과 시행일은 이 페이지에서 확인할 수 있습니다.
